Demonstrations of gethostbyname_red, the Linux eBPF/bcc version.


This traces host name lookup calls (gethostbyname() and gethostbyname2()),
 and shows the PID and command performing the lookup, the latency (duration)
of the call in milliseconds, the errno, h_errno, and the host string:

# ./gethostbyname_red
TIME      PID    COMM          LATms ERRNO H_ERRNO HOST
06:10:24  28011  wget          90.00 0     0       www.iovisor.org
06:10:28  28127  wget           0.00 0     0       www.iovisor.org
06:10:41  28404  wget           9.00 0     0       www.netflix.com
06:10:48  28544  curl          35.00 0     0       www.netflix.com.au
06:11:10  29054  curl          31.00 0     0       www.plumgrid.com
06:11:16  29195  curl           3.00 0     0       www.facebook.com
06:11:25  29404  curl          72.00 11    2       foo
06:11:28  29475  curl           1.00 11    2       foo

In this example, the first call to lookup "www.iovisor.org" took 90 ms, and
the second took 0 ms (cached). The 72 ms call in this example was to "foo",
which was an unsuccessful lookup.


USAGE message:

# ./gethostbyname_red -h
usage: gethostbyname_red.py [-h] [-p PID]

Time and inspect gethostbyname[2] calls

options:
  -h, --help     show this help message and exit
  -p, --pid PID  trace this PID only

examples:
    ./gethostbyname_red          # time and inspect gethostbyname[2] calls
    ./gethostbyname_red -p 181   # only trace PID 181
